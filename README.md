# Raji ❤️ Dev – Forever Love Story

A beautiful birthday surprise created with love for **Dev** by **Raji** on his special birthday (19 November 2026).

Built with **React.js**, **Vite**, **Framer Motion**, and **Tailored CSS**, featuring deep burgundy and glowing pink aesthetics matching the design language.

---

## ✨ Features & Story Journey

1. **🔐 Romantic Password Screen**
   - Protected with love. Requires the secret passcode (`1911`).
   - Animated glowing heart lock, subtle shake on incorrect passcode, cute error notice, and smooth unlocking transition.

2. **✈️ Pondicherry to Dubai Flight Journey**
   - Represents the distance between Pondicherry (Raji) and Dubai (Dev).
   - Starry night sky, animated flight along a glowing trajectory, clouds, and departure/destination pins.
   - Heartwarming arrival message: *"Distance means nothing when hearts are connected. ❤️"*

3. **⏳ Birthday Countdown**
   - Exact recreation of the reference UI design.
   - Real-time countdown to **19 November 2026 at 12:00 AM (Asia/Kolkata / IST)**.
   - Displays Days, Hours, Minutes, and Seconds with glowing digital typography.
   - Smart unlock logic: opens wish when midnight strikes or via instant preview.

4. **💖 Happy Birthday Chellame**
   - Emotional greeting card: *"Today is not just another day, It's the day my favorite person was born..."*
   - Elegant cursive typography, 3D sparkling heart, and glowing pink glass card.

5. **💌 Little Notes (5/5 Unfolded)**
   - Interactive emoji row (❤️, 😚, 🥰, 🤗, 😘).
   - 5 deeply meaningful love notes about how special Dev is.

6. **💍 Will You Be My Forever?**
   - Romantic proposal screen with glowing **Yes 💕** and playful **No 🙃** buttons.
   - The "No" button mischievously jumps away when hovered or tapped, ensuring Dev can only say YES!
   - Clicking "Yes" triggers a romantic heart explosion and celebratory confetti!

7. **💐 Congratulations Screen**
   - Cute animated Bear Couple holding a pink flower bouquet.
   - Celebration particles and the message: *"You won my heart forever 💕"*.

8. **📸 Our Moments (Precious Keepsakes)**
   - Polaroid-style gallery featuring the **four real couple photographs**.
   - Custom tilted frames with realistic shadows, romantic captions, and hover zoom.
   - Full-screen interactive Lightbox with navigation arrows and dates.

9. **📜 Three Love Letters**
   - Selectable parchment tabs: `Letter 1`, `Letter 2`, `Letter 3`.
   - Realistic cream paper card (`#FAF7F2`) with serif typography (`Playfair Display`).
   - Unshortened, deeply heartfelt love letters expressing devotion and the principle of *"You and me, that's it"*.

10. **🎉 Final Celebration & Love Loop**
    - *"Once again happy birthday my love 💗"*
    - Rising 3D hearts swarm and continuous celebratory confetti shower.
    - **LOVE LOOP 🔄** button smoothly resets the journey back to Page 1 without a hard page reload.

11. **🎵 Ambient Romantic Music**
    - Subtle floating music toggle in the top-right corner to play/pause the couple's romantic song.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Animations**: Framer Motion
- **Confetti**: Canvas-Confetti
- **Icons**: Lucide React
- **Typography**: Dancing Script, Great Vibes, Playfair Display, Poppins
- **Styling**: Pure modern CSS with glassmorphism, responsive grid, and custom scrollbars

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/your-username/rajidev-birthday-surprise.git
cd rajidev-birthday-surprise

# Install dependencies
npm install

# Start local development server
npm run dev

# Or build and preview
npm run build
npm run preview
```

## 🌐 Deploy to GitHub & Vercel

### Deploy to Vercel (Recommended):
1. Push your project to GitHub.
2. Sign in to [Vercel](https://vercel.com).
3. Click **Add New Project** and select your GitHub repository `rajidev-birthday-surprise`.
4. Leave build settings as default (`npm run build` and output `dist`).
5. Click **Deploy**! 🚀
